# 📌 Featured Projects

## 🛡 [VulnSneak](https://github.com/MO-Khalid-1/vulnsneak) — AI-Powered Vulnerability Detection & Automated Repair

> Graduation project — fine-tuned CodeBERT to detect source code vulnerabilities and automatically repair them using a local LLM cascade.

- 🔍 **Two-stage detection** — Binary classifier + 8-family classifier (CSRF, SQL Injection, XSS, Path Traversal, OS Command Injection, Insecure Cryptography, Insecure Deserialization, XML Injection)
- 🔧 **Region-based repair** — LLM cascade: `qwen2.5-coder:7b` → `qwen3:4b` → `gemini-2.5-flash`
- ✅ **Syntax & security validation** before accepting any patch
- 📊 **Binary model:** ~97.75% vulnerable recall | **Family model:** ~99.80% macro F1
- 🚀 **Deployed** via FastAPI on Linux server with Ollama on a separate GPU machine
